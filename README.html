Swift & Objective-C 企业级应用开发教程 ​

线上文档站：https://yzhijie.github.io/swift-objc-enterprise-guide-site/（push 到 main 后由 GitHub Actions 自动构建并发布到公开部署仓）

一套面向企业级 Apple 平台（iOS / macOS）开发的系统化中文教程，覆盖 Swift 6 语言、Objective-C 运行时、双语言混编、框架应用、性能安全、测试质量、构建部署与团队协作全链路。

教程定位与适用人群 ​

本教程以「能直接落地到企业生产环境」为目标编写，不讲玩具示例，所有知识点均结合真实企业场景（百万级 DAU App、遗留 ObjC 工程、金融类合规上架）展开。

人群背景学习建议预期收益
iOS 初中级工程师会写 SwiftUI 页面，缺乏体系按章节顺序完整学习建立语言 → 框架 → 工程化完整知识体系
ObjC 资深工程师维护遗留工程，需迁移 Swift重点读第 3、4 章，再补第 1、2 章掌握安全高效的混编与渐进迁移策略
跨端 / 后端转 Apple 平台有编程基础，不熟 Apple 生态从第 1 章开始，环境准备先跑通快速达到企业级开发门槛
Tech Lead / 架构师负责工程质量与规范重点读第 6~10 章获得性能治理、测试体系、CI/CD、规范落地与企业级实施方案

技术版本基线 ​

本教程所有示例与结论均基于以下版本验证，低于基线版本时部分特性不可用（文中会标注）。

技术基线版本说明
Swift6.0（兼容 5.10 写法）严格并发检查（Strict Concurrency）默认开启的写法
Xcode16.x构建系统、显式模块、预览宏均按 Xcode 16 讲解
iOS17 / 18@Observable 宏、SwiftData 需 iOS 17+
macOS14 (Sonoma) / 15 (Sequoia)公证（Notarization）要求以 macOS 14+ 工具链为准
SwiftUIiOS 17 时代 APIObservation 框架为默认状态管理方案
Combine持续维护版用于遗留响应式链路与新代码的边界说明
依赖管理SPM 为主，CocoaPods 兼容第 8 章给出对比选型与混用方案
自动化fastlane 2.x + GitHub Actions / Xcode Cloud签名、测试、打包、上架全自动化
端上智能（第 12 章）Core ML / Vision：iOS 15+；Foundation Models：iOS 26 / macOS 26 / Xcode 26+（本书 Xcode 27 实测）12.3/12.4 全基线可用；12.6 新框架用 @available 隔离，旧系统走降级链
国际化/无障碍（第 13 章）String Catalog：Xcode 15+；performAccessibilityAudit：Xcode 15+ / iOS 17+ 运行时13.2~13.5 全基线可用；13.6 审计 API 需 iOS 17+（模拟器可跑）
系统触点（第 14 章）WidgetKit：iOS 14+ / macOS 11+；App Intents：iOS 16+ / macOS 13+；交互 Widget：iOS 17+14.2~14.6 全基线可用；交互 Widget 与锁屏 accessory 族按 @available 标注，低版本回退 widgetURL 深链
运营闭环（第 15 章）MetricKit：iOS 13+ / macOS 12+（诊断 payload 需 iOS 14+）；CryptoKit：iOS 13+ / macOS 10.15+15.2~15.6 决策层全基线可用；MXMetricManager 系统回调需真机（模拟器不产出 payload），包内为纯逻辑解析

代码约定说明 ​

  • 所有 Swift 示例默认 Swift 6 语言模式（SWIFT_VERSION = 6.0），涉及并发代码默认通过严格并发检查；需要降级说明时会在代码注释中标注。
  • ObjC 示例使用 .m 文件并默认开启 ARC；涉及 MRC 语义仅用于讲解原理，会明确标注「仅原理演示」。
  • 代码块均带语言标签（swift / objc / ruby / yaml / bash），首行注释标明建议文件名。
  • 每个代码示例下方以「> 运行方式：」说明执行环境（REPL / swiftc 编译 / Playground / Xcode 工程 / xcodebuild）。
  • 实践经验标注约定：⚠️ 坑点、✅ 推荐做法、❌ 反例。
  • 章节之间通过相对链接互相跳转，锚点遵循 GitHub Markdown 规则（中文标题小写、空格转连字符）。

常见问题（FAQ） ​

Q1：没有 ObjC 基础，能直接学 Swift 吗？ 可以。第 1、2、5 章不依赖 ObjC；第 3 章讲运行时原理时会补必要的 ObjC 语法，第 4 章混编则假设你身处混合工程——纯 Swift 团队可将第 3、4 章作为备查手册。

Q2：示例代码都需要真机吗？ 绝大多数示例可用 REPL / swiftc / Playground / 模拟器验证；仅推送（第 5 章）、部分签名与公证流程（第 8 章）、越狱检测（第 6 章）需要真机或开发者账号，文中已逐一标注。

Q3：Xcode 版本不是 16 怎么办？ Swift 5.10 / Xcode 15 下大部分示例可运行，但 Swift 6 严格并发检查、@Observable（需 iOS 17 SDK）等行为会有差异，建议升级到基线版本后再开始第 2 章。

Q4：如何检验学习效果？ 每章「实践任务」全部完成 + 「自测题」不看书答对 80% 即达标；★★★ 任务可直接作为求职作品集素材。

Q5：团队如何共建这套教程？ 按第 9 章的规范执行：文档与代码同仓、接口变更走 RFC、发现与新版 Xcode 行为不一致时提交修复 PR。

反馈与协作 ​

学习过程中如发现示例与最新 Xcode 行为不一致，欢迎按第 9 章的规范提交 Issue 与 PR。
